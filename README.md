## 简介

《空城》是一款末日题材的第一、三人称射击封闭世界游戏。
世界已毁，只剩你、一只会跟你做买卖的狗、和一辆会坏的车，在随机生成的地图中穿行。

没有任务，也没有希望，只有孤独、引擎声和一点点不肯熄灭的生机。
在世界尽头，空城仍在沉默中喘息。

## 操作

| 键 | 作用 |
|---|---|
| WASD | 移动 |
| 鼠标 | 视角 |
| 左键 | 开火（全自动枪按住连发） |
| R | 换弹 |
| V | 近战（匕首 / 砍刀 / 撬棍） |
| 1~4 | 切枪（枪库槽位） |
| E | 搜索箱子 / 和商人交易 |
| F | 上车 / 下车 |
| B | 背包（药、油、修理包在背包里点着用） |
| 空格 / Shift | 跳 / 疾跑 |
| Esc | 菜单 |
| F1 | 调试面板（无敌、刷怪、加钱…） |

手机：自动切触屏模式，左下摇杆移动、右半屏滑动转视角、右侧按钮开火/换弹/拾取。横屏体验更好。

## 玩法

- 一局最多 5 关（也可以选无尽模式），每关地图随机生成
- 搜箱子攒东西 → 打僵尸 → 走到绿光柱撤离进下一关
- 死了背包、金币、弹药全没，只留最高到达关数
- 车是跨关资产：**开着车撤离**能带到下一关，自己走着撤离就把车丢了（下一关有概率捡回一辆）
