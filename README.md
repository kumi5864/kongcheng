# 空城 · 搜打撤

一个跑在浏览器里的第一人称搜打撤原型：随机街区、开车推进、下车搜刮、活着撤离。

**在线玩**：https://kumi5864.github.io/kongcheng/

## 操作

| 键 | 作用 |
|---|---|
| WASD | 移动 |
| 鼠标 | 视角 |
| 左键 | 开火（全自动枪按住连发） |
| R | 换弹 |
| V | 近战（匕首 / 砍刀 / 撬棍） |
| 1~4 | 切枪（枪库槽位） |
| E | 搜索箱子 / 和商人交易 |
| F | 上车 / 下车 |
| B | 背包（药、油、修理包在背包里点着用） |
| 空格 / Shift | 跳 / 疾跑 |
| Esc | 菜单 |
| F1 | 调试面板（无敌、刷怪、加钱…） |

手机：自动切触屏模式，左下摇杆移动、右半屏滑动转视角、右侧按钮开火/换弹/拾取。横屏体验更好。

## 玩法

- 一局最多 5 关（也可以选无尽模式），每关地图随机生成
- 搜箱子攒东西 → 打僵尸 → 走到绿光柱撤离进下一关
- 死了背包、金币、弹药全没，只留最高到达关数
- 车是跨关资产：**开着车撤离**能带到下一关，自己走着撤离就把车丢了（下一关有概率捡回一辆）

## 技术

单文件 HTML（17 MB，模型/贴图/音效全部内嵌），Three.js 从 CDN 加载。双击本地文件也能直接玩。
